# Finanze Famiglia

Una web app semplice per gestire le finanze insieme. Inserisci entrate e spese, visualizza grafici e cronologia.

## Setup su Vercel (5 minuti)

### Step 1: Crea un account GitHub (se non lo hai)
1. Vai su https://github.com/signup
2. Completa la registrazione con email e password
3. Verifica la mail

### Step 2: Crea un repository GitHub
1. Accedi a GitHub
2. Vai su https://github.com/new
3. Nome repository: `finanze-famiglia`
4. Seleziona "Public"
5. Clicca "Create repository"

### Step 3: Carica i file su GitHub
1. Nel repository appena creato, clicca "Add file" → "Upload files"
2. Trascina TUTTI i file/cartelle dalla tua cartella locale:
   - package.json
   - vite.config.js
   - index.html
   - src/ (cartella con App.jsx, App.css, main.jsx)
3. Scrivi un messaggio: "Initial commit"
4. Clicca "Commit changes"

### Step 4: Connetti a Vercel
1. Vai su https://vercel.com/signup
2. Clicca "Continue with GitHub"
3. Autorizza Vercel ad accedere ai tuoi repository
4. Seleziona il repository `finanze-famiglia`
5. Vercel configura automaticamente tutto
6. Clicca "Deploy"

### Step 5: Usa l'app
Una volta deployato, riceverai un URL tipo:
```
https://finanze-famiglia-xyz.vercel.app
```

Condividi questo link con tua moglie. I dati si sincronizzeranno automaticamente.

## Come Claude aggiorna l'app

Quando mi chiedi di aggiungere funzioni:
1. Io modifico i file nel repository
2. Faccio un "push" su GitHub
3. Vercel aggiorna automaticamente il sito
4. Voi vedete i cambiamenti semplicemente ricaricare la pagina

Esempio di richieste:
- "Aggiungi una sezione budget mensile"
- "Cambia i colori dello schema"
- "Aggiungi il calcolo del risparmio annuale"
- "Aggiungi notifiche quando spendo troppo"
